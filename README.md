# Billing Dashboard Assignment

A responsive billing and order summary dashboard built using React, Vite, and Tailwind CSS.

## Overview

This application provides a clean user interface for managing billing information and reviewing order details before proceeding to payment.

The dashboard includes a billing details form, coupon application section, wallet balance display, tax calculation, and payment summary.

## Installation

### Clone Repository

```bash
git clone <repository-url>
```

### Navigate to Project Folder

```bash
cd billing-dashboard
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build Production Version

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
